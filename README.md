# Description<br>

Nova-Mind YouTube Analyzer is a Flask-based web application that analyzes YouTube videos using the YouTube Data API. It extracts video statistics and comments, performs sentiment analysis, identifies common topics and keywords, detects potentially toxic users, generates relevant hashtags, calculates engagement rate, and provides smart content/SEO suggestions to help creators understand audience feedback and improve their content strategy.
